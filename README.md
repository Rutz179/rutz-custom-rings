# Rutz's World Rings

[Discord](https://discord.gg/bB7Ca666Bv)

Your own dynamic token rings for Foundry VTT. Make a ring from a ring image and a background, pick the ring this world uses, and every token with its dynamic ring on wears it.

- **Five built-in rings** — rename or redraw them for one world, or hide the ones you don't use.
- **New presets** — ring image, background texture and tint, ring thickness, inner shadow, ring colour and where the colour applies, with a preview on a token of your choice.
- **One ring per world** — *Use* sets it and asks to reload everyone; Foundry's default is one click away. Files are saved in the world's folder.
- **Tokenizer** — with Tokenizer or Tokenizer 2 active, make a preset their default frame; the same button puts the old frames back.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-custom-rings/releases/latest/download/module.json
```
Foundry VTT v12–v14 · any system · English / 한국어

GM: *Configure Settings → Rutz's World Rings → Ring presets → Open*.
